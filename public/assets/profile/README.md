# Profile design assets

Source: [Portfolio site — Профиль, node 939:22654](https://www.figma.com/design/1NZmtql1cKSZ6KtLA2a6CD/Portfolio-site?node-id=939-22654).

Exported from the authenticated Figma browser editor. SVG files retain the original vector artwork, image fills, clipping and filters; they are separated by visual element. The screen layout, headings, contact information, navigation, and publication counters are implemented in React/CSS.

- `background.svg`: original gradient artwork.
- `portrait.svg`: avatar, decorative stickers and thought bubble.
- `post-1.svg` through `post-4.svg`: original photos with their design crops.
- Remaining SVGs: original action, toolbar and publication icons.
- `fonts/wb-sans.otf` and `fonts/als-hauss.ttf`: matching fonts copied from the user's installed fonts for this prototype.
- `fonts/google-sans.ttf`: regular Google Sans from [Google Fonts](https://fonts.google.com/specimen/Google+Sans), with its OFL license alongside it.

Only chat, audio-call and video-call navigation is wired. The two remaining action buttons, QR and menu buttons are disabled. Publication category labels and cards are static in this iteration.
